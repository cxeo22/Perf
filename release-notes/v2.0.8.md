# ReTweaks 2.0.8

- Combined the live overview and Quick Start into one Dashboard.
- Grouped related tools, restored distinct sidebar entries, corrected menu scrolling and renamed groups for their contents.
- Fixed embedded-browser bundling and added packaged startup/browser checks.
- Scan currently present hardware for driver information across graphics, network, audio, Bluetooth, storage, chipset, peripherals and more. Hide unrelated vendor installers and filter by detected categories.
- Simplified duplicate background controls, renamed Windows backgrounds, and added category guidance to the welcome tour.
- Made AI help relevant to each page and changed Discord's website button to Get Retweaks.
- Added encrypted temporary file/folder transfers, expanded FPS overlay options and optional Lively wallpaper integration.

Driver installation remains user-selected. Some devices use Windows Update or official support pages rather than a direct vendor installer.

- Automatically set up missing WebView2, PawnIO and the verified PresentMon console when needed; optionally set up Lively from an animated-wallpaper action. Existing installations are retained.
